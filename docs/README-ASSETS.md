# README visuals and activity

The profile README uses the portfolio's charcoal background, white headings, gray ruler borders, compact chips, and small green availability accent. All displayed images are stored in this repository; none depend on an external badge or profile-stat rendering service.

## Static assets and animation

`assets/readme/header.gif` is a typing animation rendered at **2640 × 630**, displayed at **880 × 210**. It uses a 256-color palette without downscaling its frames. The 3× source stays sharp on high-density screens while retaining the compact banner height. The name and role remain visible throughout. The README's picture element selects the equally high-resolution `header-static.png` when the reader prefers reduced motion. Every visual has alternative text, and profile destinations are normal clickable links. GitHub can also show a paused/static image depending on its viewer settings.

The banner, badges, and technology chips are generated by `scripts/generate-readme-assets.mjs`, using the installed Sharp and React Icons packages. Install Pillow for Python 3, then run:

```sh
node scripts/generate-readme-assets.mjs
python3 scripts/pack-readme-animation.py
```

React Icons includes Simple Icons under its respective icon license. The artwork composed around the icons is local to this project.

## Public activity snapshot

```sh
node scripts/update-readme-activity.mjs
```

This reads the website's verified `/api/github-activity` response. It requires both sources to succeed, validates a continuous 365-day calendar and a descending repository ranking, and rejects malformed data before writing. The calendar counts all contribution types; repository counts are indexed public authored commits. Their totals naturally differ.

The script updates `activity.svg`, `languages.svg`, `activity.json`, and only the marked activity section in `README.md`. Two compact cards show aggregate activity counts and language proportions, matching the supplied reference's stats/languages format. There is no heatmap or repository list. Languages are measured from GitHub's public, non-fork repository code-byte totals. They describe code composition rather than proficiency or personally authored work. The four largest languages are shown; their percentages use the total of **all** languages. The unlabelled gray remainder represents the smaller languages. `activity.json` retains each repository's exact language totals so the result can be traced. Counts and date ranges have alternative text and SVG descriptions. The source is checked again daily by `.github/workflows/readme-activity.yml`, at 00:25 UTC (05:55 India time), or through a manual workflow run. GitHub may delay scheduled runs and may disable schedules on inactive public repositories.

The October 17 review verified that CSS dominates the public code totals: `tailwind-projects` alone has 3,824,769 CSS bytes. The 192,270 Jupyter Notebook bytes come from `Data-Visualization-using-python`. Notebook documents and large CSS files can outweigh many short C++ solutions. The card does not estimate coding time, discount selected languages, or claim these are all written personally by the profile owner. GitHub classifies the files using [Linguist](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-repository-languages); its [languages API](https://docs.github.com/en/rest/repos/repos#list-repository-languages) returns bytes, not contribution counts.

The workflow uses a release-pinned official checkout action and GitHub's repository-scoped automatic token. It runs on schedule or manual dispatch, with no pull-request trigger, no personal access token, and no external statistics service. It never force-pushes. Failures preserve the last committed image and counts; check the Actions tab to inspect or retry a failed run.

## Search identity correction

The old `/official/opengraphh.jpg` contained Swami Malode's name and artwork and was originally referenced by social metadata. The current metadata points to Priyanshu's own `/opengraph.png`. The legacy JPEG URL now also serves Priyanshu's preview, and the legacy placeholder logo is replaced by his local P mark.
